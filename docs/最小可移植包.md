# 最小可移植包：实现"能跑三通道法律问答"的必要文件

> 生成于 2026-09-13。基于**逐文件 import 追踪**（不是猜的），列出：
> ① **必须带的代码文件**（删一个就废一个功能）
> ② **必须带的配置文件**
> ③ **必须带的数据文件**
> ④ **哪些不用带、哪些删了没关系**
>
> 目标场景：把这套代码拷到**另一台 Windows 机器**（有 Python 3.10+、能装依赖），
> 跑起"三通道路由 + 演示界面 + 问答 API"，**不包括**：复现 E1–E5 实验、出图、校准。

---

## 0. 先分清楚两种"model"，别被 models/ 吓到

| 模型 | 在哪 | 谁在用 | 必带吗 |
|---|---|---|---|
| **DeepSeek API（回答）** | 云端，本机**无文件** | `llm_backend: deepseek`（默认） | ✅ 需要 `.env` 里的密钥 |
| **Qwen2.5-0.5B（门控草稿）** | `models/qwen2.5-0.5b-instruct/` | 算"u"纠结度 | ⚠️ 默认需要，可改成 `draft_source: local→api` 跳过 |
| **fuzi-mingcha 6.7B（兜底）** | `models/fuzi-mingcha-v1_0/`（~13 GB） | 断网 / 没密钥时 | ❌ 不用带 |
| **bge-small-zh-v1.5（向量）** | `models/bge-small-zh-v1.5/`（~100 MB） | 通道 C 语义检索 | ✅ **必带**（向量检索没它就没法查资料） |
| **Qwen2.5-1.5B** | `models/qwen2.5-1.5b-instruct/` | 旧 E1 口径（D21 时代） | ❌ 不用带 |

**最小迁移** = 只要 **bge-small-zh-v1.5**（百来 MB）+ 可选的 0.5B 草稿。
fuzi-mingcha 13 GB 那套是离线兜底，演示不带它照样能跑（走 API 回答）。

## 1. 必带源代码（`lawgate/`，共 38 个 .py）

### 路由核心（缺一个就废）
| 文件 | 为什么必须 |
|---|---|
| `lawgate/router.py` | **整条决策流水线**（意图→门控→走哪条通道），缺了就没有"路由"了 |
| `lawgate/config.py` | 读 `base.yaml`/`thresholds.json`/`.env`，解析"到底在用哪个模型" |
| `lawgate/env_setup.py` | 引导 `openai` SDK 装进 site-packages（本机 pip 装好才需要；新机器可改直接 `pip install openai`，则此文件可省） |
| `lawgate/cache.py` | 生成缓存（`gen_cache.db`），保证逐字可复现、不重复花钱 |
| `lawgate/__init__.py` | 包标识 |

### 门控（`lawgate/gate/`，5 个）
| 文件 | 作用 |
|---|---|
| `intent.py` | 意图识别（是问法条/案号/时效？） |
| `signal.py` | 门控 u（草稿 logprob 分布 → "纠结度"） |
| `complexity.py` | 复杂度评分（hybrid 路由用） |
| `calibrate.py` | **读 `configs/thresholds.json` 的 τ_b**（缺了系统静默退化成全 0.10） |
| `draft.py` | 门控草稿链（0.5B → API → 确定性伪分布三级降级） |

### 通道（`lawgate/channel/`，10 个）
| 文件 | 作用 |
|---|---|
| `b_structured.py` | **通道 B**：法条/案号/时效确定性查库 |
| `b_temporal.py` | 通道 B 的时效状态机 + 沿革链 |
| `b_case_verify.py` | 通道 B 的案号四级核验 |
| `c_semantic.py` | **通道 C**：向量检索（**必须带 `bge-small-zh-v1.5`**） |
| `llm_base.py` | 回答模型基类 + 流式协议（`respond_stream`） |
| `deepseek_llm.py` | **通道 A 默认回答后端**（DeepSeek API，读 `.env` 密钥） |
| `draft_source.py` | 门控草稿来源（`api`/`local`/`rule` 三级降级） |
| `cache.py` | （同上，已列） |
| `compat_chatglm.py` | **14 处接口缝**：加载 6.7B 兜底模型（**不带 fuzi-mingcha 可省**） |

### 知识底座（`lawgate/knowledge/`，11 个）
| 文件 | 作用 |
|---|---|
| `flk_parser.py` | 法条解析 |
| `judgment_parser.py` | 案号正则 + 法院/类型映射 + 异常代字（**单一出处**，D31） |
| `build_sqlite.py` | 建 `legal_facts.db` |
| `build_vector.py` | 建 `chroma/` 向量库（**必须带 bge 模型**） |
| `seed_corpus.py` | 13 部法 → `data/kb/legal_facts.db` 的建库脚本 |
| `seed_cases.py` | 600 合成案号库 |
| `embed.py` | 向量编码（bge 调用） |
| `store.py` | 事实库读写 |
| `rerank.py` | 检索重排 |
| `risk_terms.py` | 高风险词表 |
| `audit.py` | 人工抽验 |

### API 层（`lawgate/api/`，2 个）
| 文件 | 作用 |
|---|---|
| `app.py` | **FastAPI 服务**：`/chat` `/verify_case` `/temporal` `/health` `/trace/schema` + SSE 流式 `/chat/stream` |
| `ui.py` | **Gradio 演示界面**：双栏 + Trace 面板 + 6 个预设按钮 |

### 评测层（`lawgate/eval/`，7 个）——**做演示可不带，跑实验必须**
`benchmark.py`（评测集）、`metrics.py`（机械判分）、`baselines.py`（6 方法基线）、
`run_exp.py`（跑实验）、`io.py`、`stats.py`（Wilcoxon+bootstrap+Holm）、`plotting.py`（出图）

> **最小演示包可省略** `lawgate/eval/` 全部 7 个 + `compat_chatglm.py`（若不带 fuzi-mingcha）+ `env_setup.py`（若新机器直接 `pip install openai`）。
> 最小集合 = **30 个 .py**。

## 2. 必带配置（`configs/`，仅 2 个）

| 文件 | 作用 |
|---|---|
| `configs/base.yaml` | 总开关：`llm_backend`（deepseek/hf/local）、`causal_model`、`draft_model`、`embed_model`、`max_new_tokens`（**192**）、`db_path`、`chroma_path`、`cache_db` |
| `configs/thresholds.json` | **校准出的 τ_b**：`b1 0.29 / b2 1.0 / b3 1.0 / b4 1.0`（D33-3） |

缺 `thresholds.json` → 系统**静默**退化成全 0.10（不是报错），检索率会**暴涨**且不可复现。
**带不带看你要不要"可复现路由"**，演示可省，认真跑不能省。

## 3. 必带数据（`data/`，分三级）

### 3.1 **源头**（`data/raw/`，**绝不能删**，~2 MB）
13 个 `.txt`（人工录入的 13 部法种子语料）+ `sources.json`（溯源表）。
这是整个知识库唯一的"源"，`data/kb/` 里的库全是**从它跑出来的**。

### 3.2 **运行知识库**（`data/kb/`，**能重建但别删**，~500 MB）
| 文件 | 作用 | 删了怎么办 |
|---|---|---|
| `legal_facts.db` | 法条/案号/沿革/词典 | 重跑 `seed_corpus.py` |
| `chroma/` | 向量库（1295 篇） | 重跑 `build_vector.py`（需要 bge 模型） |
| `gen_cache.db` | 生成缓存（5429 条，含 100.9 万 token 台账） | 重跑会**重复花 API 钱**；建议带 |
| `qa_report.md` | 建库自检报告 | 可省 |
| `judgment_import_report.json` / `import_report_dryrun.md` | 导入报告 | 可省 |
| `manual_audit.csv` | 人工抽验清单 | 可省 |

### 3.3 **评测集**（`data/benchmark/`，**做演示可省，跑实验必须**，~5 MB）
`all.jsonl`(1180) / `dev.jsonl`(236) / `test.jsonl`(944) / `test_e1.jsonl`(300) /
`test_e4.jsonl`(60) / `dev_calib.jsonl`(144) / `temporal_trap.jsonl` / `case_no_verify.jsonl` /
`intent_cases_v1.json` / `counts.json` / `verify_report.md` / `construction_log.md` / `kappa_report.md` /
`simulated_annotators/` / `subsets_manifest.json`

## 6. **不带**的东西（`results/` `figures/` `docs/` `scripts/`）

| 目录 | 内容 | 不带后果 |
|---|---|---|
| `results/` `figures/` | 全部实验产物（454 jsonl / 253 json / 1 csv / 若干 png） | **能跑系统，但没有"结果"**——属于"成果"不是"实现" |
| `docs/` | 偏差/风险/总结/复现指南（`deviations.md` `risk_register.md` 等） | **系统照跑**，但可复现性证据没了 |
| `scripts/` | 30 个可复现脚本（E0–E6 / 校准 / 冒烟 / 出图） | **不能复现实验**，但演示照跑 |
| `data/benchmark/simulated_annotators/` | 模拟标注员轨迹 | 不影响系统 |

> **原则**：**`lawgate/`（源码）+ `configs/`（配置）+ `data/raw`（源头）+ `data/kb`（运行库）+
> `data/benchmark`（评测集）+ `models/bge-small-zh-v1.5`（向量）+ `requirements.txt` + `.env` + 启动脚本
> = **一套完整能跑的工程项目**。**`results/` `figures/` `docs/` `scripts/` 全是"可复现性附件"，删了不影响系统本身。**

## 7. 一句话答案

> **能运行这套三通道法律问答系统的必要文件 = 30 个 .py（`lawgate/` 包）+ 2 个配置
> （`base.yaml` + `thresholds.json`）+ 13 部法种子语料（`data/raw`）+ 运行知识库
> （`data/kb`，含 legal_facts.db + chroma + gen_cache.db）+ 向量模型（bge-small-zh-v1.5）
> + `requirements.txt` + `.env`（API 密钥）+ 启动脚本。**
>
> 评测集（`data/benchmark`）做演示可省，跑实验必带。
> `results/` `figures/` `docs/` `scripts/` 全是"结果与证据"，**不属于实现本身**。
